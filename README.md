
# FastAPI Frontend Backend CRUD

A simple Help Desk System built to understand how frontend and backend communicate using FastAPI.

## Features

- Create a Ticket
- View All Tickets
- Update a Ticket
- Delete a Ticket

## Technologies Used

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Python
- FastAPI

**Data Storage:**
- JSON

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run Backend

```bash
uvicorn main:app --reload
```

## Open Frontend

Open `frontend/index.html` in your browser.

## API Documentation

After starting the backend, visit:

```text
http://127.0.0.1:8000/docs
```

## Purpose

The purpose of this project is to understand CRUD APIs and frontend-backend communication using FastAPI.
